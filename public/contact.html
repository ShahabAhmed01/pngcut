GitHub (preferred)

Open an issue on the issue tracker.

Include in a bug report

  • Browser and version (e.g. Chrome 126, Firefox 128, Safari 17).
  • Operating system and device type (desktop or mobile).
  • Input format and approximate size (image dimensions, or video resolution/duration).
  • Which mode: image editor, bulk, or video.
  • The exact error message shown.
  • Whether WebGPU was active (shown in the status chip), and whether CPU fallback worked.

Please do not upload private images or videos as part of a bug report unless you are sure you want to share them. Describe the problem instead; if a repro is needed, use a non-private sample file.
